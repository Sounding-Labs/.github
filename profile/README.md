# Sounding Labs

A corridor-integrity monitor for the Stellar network.

Sounding prices stablecoin → fiat-token corridors across trade sizes, scores every route against independent mid-market rates, and states plainly when none of them are worth taking.

## Why Sounding

- Price the whole corridor — Compare routes across trade sizes instead of quoting a single headline rate.
- Score against the truth — Every path is measured against independent mid-market rates, not the providers' own numbers.
- Say don't send this — When the honest answer is that a corridor is not worth taking, Sounding says so.
