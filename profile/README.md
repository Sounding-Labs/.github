## Stellar-native by design

This project belongs to the **Stellar** ecosystem — value moves on-chain, and the public ledger means anyone can audit it.

## What we do

Sounding prices stablecoin → fiat-token corridors across trade sizes, scores every route against independent mid-market rates, and states plainly when none of them are worth taking.

1. **Price the whole corridor** — Compare routes across trade sizes instead of quoting a single headline rate.
2. **Score against the truth** — Every path is measured against independent mid-market rates, not the providers' own numbers.
3. **Say don't send this** — When the honest answer is that a corridor is not worth taking, Sounding says so.
